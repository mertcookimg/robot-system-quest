How to Play

WASD / 矢印 / 🎮 左スティック・十字 移動 / 旋回
Shift / X / 🎮 LB・RB・LT・RT ブースト
Space / 🎮 A 停止 / 決定・アクション・SETTINGS（ステージ依存）
R / 🎮 Start リスタート
🎮 Select / Back ステージメニューの開閉 (キーボードはステージ pill を直接クリック)
🎮 L3 (左スティック押込み) ターミナルのコマンドパレット (↑↓ 選択 / A 実行 / B 閉じる)
? / 🎮 R3 (右スティック押込み) ヘルプ表示 / 閉じる
Esc / 🎮 B 閉じる

各ステージ固有の操作 (Block Editor・配線パズル・Nav2 など) は、そのステージの GUIDE (📖) と画面上のヒントに表示されます。

WASD / Arrows / 🎮 Left Stick · D-Pad Move / Turn
Shift / X / 🎮 LB·RB·LT·RT Boost
Space / 🎮 A Stop / confirm, action, or SETTINGS (stage-dependent)
R / 🎮 Start Restart
🎮 Select / Back Open / close Stage Menu (keyboard: click a stage pill)
🎮 L3 (left-stick click) Terminal command palette (↑↓ select / A run / B close)
? / 🎮 R3 (right-stick click) Show / hide Help
Esc / 🎮 B Close

Stage-specific controls (Block Editor, wire puzzles, Nav2, …) are shown in that stage's GUIDE (📖) and as on-screen hints.
